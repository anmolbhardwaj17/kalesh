# Area knowledge files

One file per docs/READ_MAP.md area, named after the heading in kebab case (for example `player-movement-and-camera.md`). One gotcha per line, merged into an existing line when the topic is already there. Builders add lines at the end of each task; the planner's CONSOLIDATE mode keeps each file under about 12 KB.

Areas now: `verify-and-harness-tooling.md`, `rendering-and-look.md`, `ui-and-input.md`, `assets-and-ingest.md`, `driving-and-camera.md`, `world-and-map.md`, `world-runtime.md`, `characters-ai-combat.md`, `story-runtime.md` (the READ_MAP "Map inspector" area shares `world-and-map.md`).
