# Parody shop names per area

Task P2-067. Rule (decisions.md): boards use parodies of famous Delhi shops and brands, never the real names. Each parody keeps the feel and changes the core word and spelling (never one letter off, no slogans, no logos). In the names files these entries carry `parody: true`, `board_style`, an optional `tagline`, and Hindi in `text.deva`. Humour aims at commerce only: no religious places or titles, communities, castes, real people, politicians or parties.
