# Sign board fonts (P2-048)

Every font here is free to download and use, under the SIL Open Font License 1.1 (OFL.txt: the licence text as shipped with Mukta; each family carries its own copyright line in the font file). They are downloaded
from the Google Fonts repository (github.com/google/fonts, folder `ofl/`) on 2026-11-14 and used only to draw the sign
atlases (tools/kits/make_signs.mjs, shaped by tools/kits/signtext.mjs). No font is shipped inside the game build: the
lettering is baked into the atlas images.
